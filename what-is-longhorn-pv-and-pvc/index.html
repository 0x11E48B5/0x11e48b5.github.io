Longhorn, local storage for your kubernetes cluster

11E48B5
2025-04-30
devops, kubernetes, longhorn, pvc

What is Longhorn?

Longhorn is a cloud-native distributed block storage system for Kubernetes. It was developed by Rancher Labs and is now a CNCF project. Longhorn enables highly available, persistent storage for your Kubernetes workloads using containers and microservices. Longhorn enables you to create volumes for your containers in bare-metal systems also. Here is the key features of Longhorn;

  • Distributed Block Storage: It turns the local disks of your Kubernetes nodes into distributed storage volumes.
  • Highly Available Volumes: Each volume can be replicated across multiple nodes for fault tolerance.
  • Snapshots and Backups: Supports volume snapshots and backup/restore, including backup to external S3-compatible object storage (e.g., MinIO).
  • Lightweight and Easy to Use: Designed to be simple to deploy and operate.
  • GUI and CLI Management: Offers both a web UI and kubectl integration.
  • Disaster Recovery (DR) Volumes: Supports DR volumes in different clusters or regions.

Longhorn uses replication to make copies of data to ensure high availability and data redundancy. When a Longhorn volume is created, the user specifies the number of replicas that should be created for the volume. Each replica is a complete copy of the volume data and is stored on a different physical disk on a different node within the Kubernetes cluster.

How it works?

  1. Longhorn Manager runs as a Kubernetes deployment and orchestrates volume creation, scheduling, and replication.
  2. Longhorn Engine runs per volume and performs actual block storage read/write operations.
  3. Storage is replicated across multiple nodes for redundancy.

How to install Longhorn?

Firstly, you must have installed kubernetes with version > v1.21. After make sure open-iscsi installed and iscsid daemon is running on all nodes.

Longhorn relies on iscsiadm which is the host to provide persistent volumes to Kubernetes. Open-iSCSI is an implementation of the iSCSI (Internet Small Computer System Interface) protocol for Linux. It enables communication between iSCSI initiators and targets over an IP network.
